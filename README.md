# AR Solar System 🌌🪐

An Augmented Reality Solar System project built with Unity and Vuforia Engine. The project uses AR image tracking to place and display an interactive 3D Solar System in the real world through a mobile device.

## ✨ Features

- Augmented Reality Solar System
- Image Target tracking using Vuforia Engine
- 3D Sun and planets
- Planet rotation and movement
- Interactive AR visualization
- Real-world AR placement through a mobile camera

## 🛠 Technologies Used

- Unity 2022.3
- C#
- Vuforia Engine 11.4.4
- AR Image Tracking
- 3D Models and Materials
- Android / IL2CPP

## 🪐 Solar System

The project includes the following celestial bodies:

- Sun
- Mercury
- Venus
- Earth
- Moon
- Mars
- Jupiter
- Saturn
- Uranus
- Neptune

## 🎯 AR Image Tracking

Vuforia Engine is used to recognize the Solar System image target. Once the target is detected through the device camera, the 3D Solar System is displayed in augmented reality.

## How to Run
1. Clone or download this repository.
2. Open the project using Unity 2022.3.
3. Open the main scene from:
   `Assets/Scenes/SampleScene.unity`
4. Connect a compatible Android device.
5. Build and run the project.
6. Point the device camera toward the AR image target.
7. The Solar System will appear in augmented reality.

## 📱 Platform
The project is designed for Android AR testing using Vuforia Engine.
